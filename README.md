
# GitHub Analyzer

A Python application that shows github user's info using the GitHub API.

## Features

- Fetch GitHub user profile information
- Display followers, following , public repo count, etc.

## Tech Stack

- Python
- PyGithub

## Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/SumitPaldiya/Github-Analyzer.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Github-Analyzer
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

## Usage

Run the application:

```bash
python main.py
```
Choose your desired preference.  
Enter a valid GitHub username when prompted.
